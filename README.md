# Luke Esperiquette | Portfolio

I am a mechanical engineer with a B.S. from Cal Poly Pomona, working as a Project Engineer on building controls. My interests are field robotics for environmental monitoring, and the sensing, calibration and control that make measurements trustworthy.

This site collects my work experience, projects and research, with the reports and posters behind each entry:

- **Projects:** a self-balancing platform, an eddy current tachometer, a thermal energy storage CFD study, and a Bayes localisation filter that I am using to learn probabilistic robotics.
- **Research:** Cal Poly Pomona STARS work on quantum technologies for autonomous vehicles, a UAV and ground-data correlation study, and the WISTLS sampling drill senior project.
- **Experience:** Sunbelt Controls, Siemens, and Air Force Civilian Service at Edwards AFB.
